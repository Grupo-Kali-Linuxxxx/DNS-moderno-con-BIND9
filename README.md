# DNS-moderno-con-BIND9
Configura el DNS autoritativo del dominio de laboratorio de tu organización y demuestra con dig que todos los registros resuelven correctamente desde un cliente.
INSTRUCCIONES
• Laboratorio 6: análisis de resoluciones reales con dig +trace y diagrama de la jerarquía DNS.
• Laboratorio 7: BIND9 con la zona directa; validación con named-checkconf y named-checkzone.
• Laboratorio 8: zona inversa, servidor secundario con transferencia de zona restringida y cliente configurado para usar el DNS propio.
• Cuadro comparativo con el DNS de Windows Server y bitácora de IA.
